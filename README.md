# Project-Euler-Problems
My Python solutions to the [Project Euler](https://projecteuler.net/about) problems. These problems are mostly based on number theory and analysis, some on counting and combinatorics. They provide great programming practice for students familiar with the basics of these topics. While I solve the problems I am constantly researching and thinking about algorithms, data structures and time complexity in order to find correct and somewhat efficient solutions. I look forward to updating this repository as I solve more of these problems!
